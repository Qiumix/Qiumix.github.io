使用了 kd，这是一个go编写的程序，支持daemon模式来提升性能。

直接kd $word_to_query 就可以使用了。

然后默认情况下无法模糊查询，在README.md里还是todo状态。

但是我们就做不到模糊查询了吗？

这个词典会从网络上下载一个SQLite词典数据库到 /.cache/kdcache/kd_data.db, 既然是这种通用的数据存储方式，那我们的操作空间就很多了。

进入数据库后能看到表的结构是这样的

一份存中文，一份存英文。

我们只需要select query from en就可以获得全部的单词了, 这时候请出我们的fzf，可以让fzf候选单词，就实现了模糊查询单词， 利用fzf的–preview可以实现实时预览，然后利用expect包里的unbuffer可以实现彩色打印。

最终结果就是这样了

function k
    if test (count $argv) -gt 0
        kd $argv
        return
    end

    sqlite3 ~/.cache/kdcache/kd_data.db "select query from en" \
        | fzf \
        --ansi \
        --preview "unbuffer kd {}" \
        --height "60%" \
        --prompt="select> " \
        --layout=reverse \
        --input-border=rounded \
        --list-border=rounded \
        --preview-border=rounded \
        --input-label="   input " \
        --list-label="   word lists " \
        --preview-label=" 󰇆 description " \
        --pointer="❯" \
        --marker="✓" \
        --border=rounded \
        --preview-window "right:65%:nowrap" \
        --color="bg+:#3c3836,fg+:#fbf1c7,hl:#fabd2f,hl+:#fabd2f" \
        --color="input-border:#83a598,list-border:#504945,preview-border:#b8bb26" \
        --color="prompt:#fe8019,pointer:#fb4934,marker:#b8bb26,label:#ebdbb2" \
        | xargs -r kd
end
